01

An interface over a protocol

Swing clients send datagrams to a server. Login and message handling are distinct flows, client handlers run on threads, and group membership is maintained separately from direct-message recipients.

02

A little persistence

The server stores conversation history in files and sends older messages when a client joins. The code makes the path from a user action to a packet, a handler, and a visible message unusually direct.

03

A conversation on the local machine

The film runs two clients and a server on loopback using new test messages. Delivery is checked in the receiving client before the capture proceeds. A routing bug caused shared-socket handlers to use their own recipient instead of the packet recipient; this was repaired in the isolated capture copy, along with history attribution. The historical repository is unchanged.

04

The boundary of the experiment

This is a networking study. Authentication, transport security, and delivery guarantees are not claimed. The recording contains only locally generated test conversations.
