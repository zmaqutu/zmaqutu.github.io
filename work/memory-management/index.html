01

Follow the bits

The program reads eight-byte words, reverses their byte order, separates a page index from an offset, and looks up the frame in a fixed table. The translated addresses are formatted and written to an output file.

02

A deliberately small model

This models a fixed mapping, not a complete memory manager. The code wraps page indices modulo the table length and only retains addresses within its chosen bit width. Those choices make the scope clear: a small exercise in representation and translation.
