02 → 03 / FOLLOWING THE THROUGHLINE
03 / THE THROUGHLINEA HISTORY OF FOLLOWING QUESTIONS

The tools change.
The curiosity stays.

My work connects frontend engineering in React and TypeScript with backend and systems programming in Java, C++ and Python. Machine learning, data exploration and visual computing give those systems something to reveal.

First, the mechanics: water moving downhill, packets crossing a network, threads waiting for one another.

Then, the behavior: pixels becoming shapes, agents learning a route, a network recognizing a digit.

Now, the experience: building interfaces that let someone else see, question, and play with those ideas.

The thread running through it all is making a system understandable by making it visible.

2020—2021

Under the surface

Java, C++, Python.
Systems and first principles.

2021—2023

Into the scene

React, Three.js, TensorFlow.js.
Algorithms with a visible life.

2024—2026

Room to explore

Workers, vectors, spatial interfaces.
Experiments others can navigate.
